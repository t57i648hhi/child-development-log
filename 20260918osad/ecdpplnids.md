# 女人产后气血不足喝八珍汤的禁忌有哪些？

> 更新时间：2026-09-18 (UTC+8)

我生孩子的时候子宫收缩不好，流了很多血，多亏医生医技优秀，最终我还是没有太大问题。但是产后可能是因为气血不足吧，整个人看起来精神状态和健康情况都不是很好，再加上还要给孩子喂奶，现在整个人没什么气色。妈妈最近给我抓了八珍汤喝，想了解一下喝八珍汤的禁忌有哪些？

喝八珍汤的禁忌其实并不多，只要注意在服用药物期间不要随意增加其他药物一同服用，因为这很可能会影响药效，甚至出现不良反应。还有就是在服用期间一定要遵照医生医嘱给出的服用剂量决定用药量，盲目的喝药会存在安全隐患。除此之外，大家还要注意三个八珍丸的禁忌症，感冒期是不能喝该药汤，会导致病情加重，月经来潮也不能喝，会让出血量变多，最后就是脾胃虚弱、湿热体质的人不易服用，应先调理再喝。
八珍汤，中医方剂名，别名八珍散，其源于《正体类要》。八珍丸的组成药方主要由人参、茯苓、甘草、白术、当归、熟地、白芍、川芎等药材，具有补气、养血之功效。常用于病后失调、外病失治、失血过多等慢性消耗性疾病。
八珍汤是由四物汤和四君子汤组合而成。一共八味中药，四物汤是补血圣药，四君子汤是补气圣药，八珍汤就是在此基础上将两方合二为一的经典名方，可以气血双补。但在服用期间需要注意以下禁忌：

- 1. 感冒时服用会加重感冒症状，或其他症状；
- 2. 月经来潮时服用会让血液循环增多，导致血液量增加，可引起严重出血；
- 3. 脾胃虚弱的人，不宜使用，应该先调理脾胃虚寒证。湿热体质不宜使用，应以先治疗湿热为主；
- 4. 不要随意例如添加其他药物的处方，如果有需要搭配，需要请专业的医生决定；
- 5. 需要辩证的治疗，在把了脉搏后，根据医生给出的剂量服用，不同病患需要的剂量是不一样的。
除此之外，八珍汤也不要长期食用。因为本身八珍汤的八种药材就属热性中药，长时间喝八珍汤，很容易导致肝火过旺，对肝造成不可逆的损伤。
